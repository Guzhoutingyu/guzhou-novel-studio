# 🚢 孤舟小说工作室 | Guzhou Novel Studio

> 一人一舟，渡创作之海

一套完整的AI辅助小说创作技能系统，整合调研、创作、风格、质检、长篇管理五大模块，支持短篇爆款、知乎盐选、严肃长篇等多种创作场景。

---

## ✨ 核心特点

### 🎯 五位一体，全流程覆盖

```
调研(Research) → 创作(Creation) → 风格(Style) → 质检(QA) → 长篇管理(Studio)
```

| 模块 | 功能 | 核心能力 |
|------|------|----------|
| **调研模块** | 开题/续写/改写调研 | 先问再写，避免卡文 |
| **创作模块** | 短篇/盐选/长篇创作 | 平台规范，技法支持 |
| **风格模块** | 风格提取与进化 | Style-DNA，去AI化 |
| **质检模块** | 一致性检查 | 10维度检测，回归测试 |
| **长篇管理** | 项目管理+记忆系统 | 伏笔追踪，时间线管理 |

### 🔄 智能路由，自动调度

根据用户需求自动识别场景，调度对应模块：

| 用户说 | 自动路由到 |
|--------|-----------|
| 「写个短篇」「盐选投稿」| 创作模块（短篇流程）|
| 「开题」「调研」「卡文了」| 调研模块 |
| 「续写」「第X章」| 长篇创作 + 质检 |
| 「检查一下」「QA」| 质检模块 |
| 「学习XX风格」| 风格模块 |

### 📝 支持多种创作场景

- **微小说爆款**（800-2200字）：六拍快反~十拍多重反转结构
- **知乎盐选短篇**（8000字起）：符合盐选投稿规范，付费卡点设计
- **严肃长篇创作**：完整项目管理，风格进化，质量检测闭环

## 🔧 模块详解

### 1. 调研模块 (Researcher)

**核心能力**：开题调研、续写调研、改写调研

**核心原则**：先读 → 先问 → 再给方案

**触发场景**：
- 「帮我理一下后面几章怎么走」
- 「卡文了，先调研再写」
- 「这段不满意，先调研再改」

### 2. 创作模块 (Creator)

**核心能力**：短篇爆款、盐选短篇、长篇连载

**支持结构**：
- 微小说：六拍快反、七拍基础、八拍情绪、九拍双线、十拍多重反转
- 盐选短篇：盐选七拍、压抑-爆发变体、导语前置型、付费卡点型

**技法支持**：双线镜像叙事、灰色人设、草蛇灰线伏笔、硬核智斗

### 3. 风格模块 (Stylist)

**核心能力**：
- Style-DNA 提取：从范文中提取风格特征
- 风格进化分析：以上一章为标杆持续进化
- 去AI化：杜绝翻译腔、模板句、机械重复

**内置风格库**：
- 《伊豆的舞女》叙事风格
- 《挪威的森林》叙事风格
- 王家卫电影风格
- 云辉随笔风格

### 4. 质检模块 (QA)

**10大检测维度**：

| 维度 | 检查内容 |
|------|----------|
| 人设一致性 | 性格、口头禅、行为习惯前后矛盾 |
| 时间线一致性 | 日期顺序、事件先后、年龄对应 |
| 情节逻辑 | 因果关系、动机合理性、行为逻辑 |
| 对话合理性 | 说话方式、引用准确、语境违和 |
| 伏笔闭环 | 悬而未决的线索 |
| 称呼一致性 | 角色称呼前后统一 |
| 场景一致性 | 地点描述、空间布局矛盾 |
| 物品一致性 | 关键物品出现/消失/转移合理性 |
| 情感逻辑 | 情绪反应是否符合性格和情境 |
| 文风自然度 | AI味、翻译腔、模板句检测 |

**问题分级**：BLOCKER（致命）→ CRITICAL（严重）→ MAJOR（一般）→ MINOR（轻微）

### 5. 长篇管理模块 (Studio)

**核心能力**：
- 项目初始化：统一目录结构
- 六步强制写作流程：加载上下文 → 风格进化 → 反馈规避 → 要点提取 → 执行写作 → 大纲覆盖检查
- 记忆系统：伏笔追踪、时间线管理、人物状态
- 本地备份：章节自动保存
